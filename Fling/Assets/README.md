# Assets

Required image assets for the MSIX package:

| File | Size | Purpose |
|------|------|---------|
| StoreLogo.png | 50x50 | Store listing |
| Square150x150Logo.png | 150x150 | Start menu tile |
| Square44x44Logo.png | 44x44 | Taskbar icon |
| Wide310x150Logo.png | 310x150 | Wide tile |
| LockScreenLogo.png | 24x24 | Lock screen |
| SplashScreen.png | 620x300 | Splash screen |
| TrayIcon.ico | Multi-size | System tray |

Generate these using Visual Studio's Asset Generator or create manually.

For development, you can use solid color placeholders.
